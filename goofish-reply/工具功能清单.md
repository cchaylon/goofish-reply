# 闲鱼自动回复工具 - 功能清单

---

## 一、账号登录

| 功能 | 说明 | 状态 |
|------|------|------|
| Cookie 登录 | 支持输入闲鱼账号 Cookie 进行登录 | ✅ |
| Cookie 验证 | 自动验证 Cookie 有效性 | ✅ |
| 登录状态检测 | 实时显示账号登录状态 | ✅ |
| 登录过期提醒 | Cookie 过期时自动提醒重新登录 | ✅ |

## 二、自动回复配置

| 功能 | 说明 | 状态 |
|------|------|------|
| 通用关键词回复 | 设置全局关键词及对应回复内容 | ✅ |
| 商品专属关键词 | 为特定商品设置专用回复规则 | ✅ |
| 默认回复 | 设置未匹配任何规则时的兜底回复 | ✅ |
| 回复优先级 | 指定商品回复 > 商品专用关键词 > 通用关键词 > 默认回复 | ✅ |
| 关键词匹配模式 | 支持精确匹配、模糊匹配 | ✅ |
| 回复模板变量 | 支持用户名、商品信息等动态变量 | ✅ |
| 批量导入关键词 | 支持批量导入关键词配置 | ✅ |
| 关键词导出 | 支持导出关键词配置备份 | ✅ |

## 三、消息管理

| 功能 | 说明 | 状态 |
|------|------|------|
| 消息监听 | 实时监听闲鱼聊天消息 | ✅ |
| 消息解析 | 解析消息内容和商品信息 | ✅ |
| 自动回复 | 根据配置自动发送回复消息 | ✅ |
| 回复记录 | 记录所有自动回复操作 | ✅ |

## 四、工具控制

| 功能 | 说明 | 状态 |
|------|------|------|
| 启动自动回复 | 开启自动回复服务 | ✅ |
| 停止自动回复 | 停止自动回复服务 | ✅ |
| 服务状态 | 显示自动回复服务运行状态 | ✅ |
